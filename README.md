# Sheik Anik | Academic Portfolio

Developed with React. This repository contains my personal academic homepage with structured content sections and editable data files for easy maintenance.

## Highlights

- Research and about section
- Teaching and updates sections
- Publications listing
- Current students and alumni entries
- Sidebar with profile, office location, email, and social links

## Project structure

- `src/components/` — page sections and UI components
- `src/data/` — editable content for publications, teaching, updates, students, and timeline
- `src/styles/index.css` — site styling
- `src/App.jsx` — section composition
